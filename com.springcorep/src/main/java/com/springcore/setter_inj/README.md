# Setter Injection in Spring Framework

## 📌 Overview
This module demonstrates how **Spring Framework** performs Setter-Based Dependency Injection using XML configuration.  
It shows how values are injected into a Java class (`Student`) through setter methods and managed by the Spring IoC container.

---

## 🎯 What This Project Demonstrates
- How Spring container loads configuration file  
- How beans are defined in XML  
- How property values are injected into a class  
- How multiple beans of the same class can be created  
- Different ways to inject values in Spring  

---

## 🧠 Injection Methods Used
Three different approaches are demonstrated:

1. **Traditional property injection** using separate `<value>` elements  
2. **Short-form property injection** using `value` attributes  
3. **p-namespace injection** (clean and simplified configuration style)  

This helps understand both beginner and optimized XML configuration techniques.

---

## 📂 Project Flow
1. Spring container starts.  
2. Configuration file is loaded.  
3. Student beans are created.  
4. Setter methods are automatically called by Spring.  
5. Injected values are printed in the console.  

This shows how Spring controls object creation and dependency management.

---

After going through this module, you will understand:
- What is **Inversion of Control (IoC)**  
- How **Setter Injection** works internally  
- How Spring manages **bean lifecycle**  
- How to configure beans using XML  
- Why Dependency Injection reduces tight coupling
